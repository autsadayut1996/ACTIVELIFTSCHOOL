# ActiveLift School — MVP Prototype

แอปออกกำลังกายแนวคอมมิวนิตี้ + เกม สำหรับนักเรียน–นักศึกษาไทย
**School League · Anti-toxic Gamification · Battle Pass ราคาไทย · Community แบบเกาหลีๆ**

นี่คือ clickable prototype ของ Core Loop ตามแผนธุรกิจ (ส่วนที่ 4 และ 9 “Prototype”) สำหรับให้นักเรียน 10–15 คนลองกดก่อนลงทุนสร้างแอปจริง ไม่มี backend ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ (localStorage)

## วิธีเปิด

- เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้อง build)
- หรือรันเซิร์ฟเวอร์ในเครื่อง: `npm start` แล้วเปิด <http://localhost:8080> (เปิดจากมือถือในวง Wi-Fi เดียวกันได้)
- รันเทสต์ logic: `npm test` (Node 18+)

ออกแบบเป็น mobile-first (กว้างสุด 440px) ลองเปิดบนมือถือจะเหมือนแอปที่สุด

## สิ่งที่มีใน prototype

| ฟีเจอร์ (จากแผน) | ใน prototype |
| --- | --- |
| Daily Check-in + Anti-toxic XP | เช็คอินวันละครั้ง ได้ XP จาก “ทำตามที่ตั้งใจ” (ครบ = 20 XP, ได้นิดหน่อย = 10 XP) + โบนัส streak สูงสุด +25 ไม่มีช่องน้ำหนัก/BMI/แคลอรี่ |
| Streak Freeze | พลาดได้ 2 วัน/สัปดาห์ streak ไม่หาย แสดงเป็นช่อง ❄️ |
| ข้อความให้กำลังใจ | ข้อความเชิงบวกหลังเช็คอิน, เลือกอารมณ์หลังขยับ (ไม่บังคับ) |
| Mini Room | แต่งห้อง/ตัวละครด้วยเหรียญ, ของปลดล็อกจาก streak 3 และ 7 วัน, ร้านขายเฉพาะ cosmetic |
| เลือกโรงเรียน/มหาวิทยาลัยตอนสมัคร | Dropdown สถาบัน + ห้อง/คณะ ไม่ต้อง verify อีเมล |
| Close-Friends Group (5–10 คน) | สร้าง/เข้ากลุ่มด้วยรหัส, เห็น streak กันและกัน, Group streak (นับเมื่อเพื่อนครึ่งหนึ่งขยับ), ส่งกำลังใจด้วยข้อความสำเร็จรูป, เยี่ยมห้องเพื่อน |
| Buddy-Matching อัตโนมัติ | จับคู่จากสถาบันเดียวกันตามระดับการขยับ เวลาว่าง และกิจกรรมที่ชอบ, ช่วงลองคุย 3 วัน, รายงาน/บล็อก, ไม่แชร์ข้อมูลติดต่อจนทั้งคู่ยืนยัน |
| โหมดไม่มีใครเห็นชั่วคราว | เปิดอัตโนมัติ 14 วันแรก จากนั้น *ถาม* ก่อนเปิดเผย ไม่เปิดเองอัตโนมัติ; ระดับการมองเห็น: เฉพาะฉัน → เพื่อนสนิท → ห้อง/คณะ → ทั้งโรงเรียน |
| Exit survey | เมื่อ streak ขาด ถามเหตุผลแบบไม่กดดัน (ไม่บังคับ) |
| School League (Phase 2) | การ์ดตัวอย่าง: อันดับคิดจาก XP รวมทั้งโรงเรียน ไม่ใช่รายบุคคล |

### เครื่องมือทดสอบ (แท็บ “ฉัน”)

- **ข้ามไปวันถัดไป** จำลองวันเพื่อทดสอบ streak / freeze / group streak / exit survey โดยไม่ต้องรอจริง
- **ส่งออกข้อมูลทดสอบ** ดาวน์โหลด JSON ของ session (เช็คอิน อารมณ์ คำตอบ exit survey) ไว้วิเคราะห์ D2/D7 retention
- **เริ่มใหม่ทั้งหมด** ล้างข้อมูลเพื่อให้ผู้ทดสอบคนถัดไปใช้

เพื่อน กลุ่ม และบัดดี้ในแอปเป็นผู้ใช้จำลอง (`js/data.js`) ที่เช็คอินแบบสุ่มคงที่ต่อวัน เพื่อให้ฟีเจอร์คอมมิวนิตี้ทดสอบได้โดยไม่ต้องมีเซิร์ฟเวอร์

## โครงสร้างไฟล์

```
index.html        หน้าเดียวของแอป
css/style.css     ธีม soft/pastel แบบเกาหลี
js/logic.js       logic ล้วน: วันที่, streak + freeze, XP/เลเวล, group streak, buddy score (มีเทสต์)
js/data.js        ข้อมูลสถาบัน กิจกรรม ไอเท็ม และผู้ใช้จำลอง
js/app.js         UI และการจัดการ state
tests/            เทสต์ด้วย node:test
docs/             สรุปแผนธุรกิจและแผนทดสอบ
```
