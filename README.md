# ActiveLift School — MVP Prototype

แอปออกกำลังกายแนวคอมมิวนิตี้ + เกม สำหรับนักเรียน–นักศึกษาไทย
**School League · Anti-toxic Gamification · Battle Pass ราคาไทย · Community แบบเกาหลีๆ**

เริ่มจาก clickable prototype ของ Core Loop ตามแผนธุรกิจ (ส่วนที่ 4 และ 9 “Prototype”) และตอนนี้มีเซิร์ฟเวอร์จริงสำหรับผู้ใช้หลายคนแล้ว (Node.js + SQLite ไม่มี dependency ภายนอก)

## วิธีเปิด

มี 2 โหมด ใช้โค้ดหน้าแอปชุดเดียวกัน:

- **ออนไลน์ (ผู้ใช้จริง):** `npm run server` แล้วเปิด <http://localhost:8080> → สมัครด้วยชื่อผู้ใช้ + รหัสผ่าน ข้อมูลกลุ่ม บัดดี้ กำลังใจ League และทัวร์นาเมนต์ใช้ร่วมกันข้ามเครื่องจริง (`npm run dev` = เปิดปุ่มข้ามวันสำหรับทดสอบ) รายละเอียดใน [`docs/backend.md`](docs/backend.md)
- **ออฟไลน์ (prototype):** เปิดไฟล์ `index.html` ตรงๆ หรือ host แบบ static (เช่น GitHub Pages) — ทุกอย่างอยู่ในเบราว์เซอร์ เพื่อนเป็นผู้ใช้จำลอง เหมาะกับการทดสอบคนเดียว

รันเทสต์ทั้งหมด: `npm test` (ต้องใช้ Node 22.13 ขึ้นไป)

**ขึ้นเซิร์ฟเวอร์ทดสอบให้นักเรียนใช้จริง:** มี `Dockerfile` + `fly.toml` พร้อมรหัสเชิญ, หน้าผลการทดสอบ `/admin/` (retention วันที่ 2/7, North Star, ราคา 59 vs 99 ฯลฯ) และสำรองข้อมูลอัตโนมัติ — ทำตาม [`docs/deploy.md`](docs/deploy.md)

ออกแบบเป็น mobile-first (กว้างสุด 440px) ลองเปิดบนมือถือจะเหมือนแอปที่สุด

## Landing page (fake door test)

`landing/index.html` คือหน้าลงชื่อรอเปิดตัว ใช้วัดความสนใจก่อนสร้างแอปจริง: A/B test ข้อความหลัก (“ไม่มีใครตัดสินรูปร่าง” vs “ออกกำลังกายแบบเกม”), ฟอร์มลงชื่อ (บทบาท, โรงเรียน, กิจกรรมที่สนใจ, อีเมล + ยินยอม), ปุ่มแชร์ LINE และนับ event ทุกขั้นของ funnel ส่งเข้า Google Sheets ได้โดยไม่ต้องมีเซิร์ฟเวอร์ — วิธีตั้งค่าและอ่านผลอยู่ใน [`docs/landing-setup.md`](docs/landing-setup.md)

## สิ่งที่มีใน prototype

| ฟีเจอร์ (จากแผน) | ใน prototype |
| --- | --- |
| Daily Check-in + Anti-toxic XP | เช็คอินวันละครั้ง ได้ XP จาก “ทำตามที่ตั้งใจ” (ครบ = 20 XP, ได้นิดหน่อย = 10 XP) + โบนัส streak สูงสุด +25 ไม่มีช่องน้ำหนัก/BMI/แคลอรี่ |
| Streak Freeze | พลาดได้ 2 วัน/สัปดาห์ streak ไม่หาย แสดงเป็นช่อง ❄️ |
| ข้อความให้กำลังใจ | ข้อความเชิงบวกหลังเช็คอิน, เลือกอารมณ์หลังขยับ (ไม่บังคับ) |
| Mini Room | แต่งห้อง/ตัวละครด้วยเหรียญ, ของปลดล็อกจาก streak 3 และ 7 วัน, ร้านขายเฉพาะ cosmetic |
| เลือกโรงเรียน/มหาวิทยาลัยตอนสมัคร | Dropdown สถาบัน + ห้อง/คณะ ไม่ต้อง verify อีเมล |
| Close-Friends Group (5–10 คน) | สร้าง/เข้ากลุ่มด้วยรหัส, เห็น streak กันและกัน, Group streak (นับเมื่อเพื่อนครึ่งหนึ่งขยับ), ส่งกำลังใจด้วยข้อความสำเร็จรูป, เยี่ยมห้องเพื่อน |
| Buddy-Matching อัตโนมัติ | จับคู่จากสถาบันเดียวกันตามระดับการขยับ เวลาว่าง และกิจกรรมที่ชอบ, ช่วงลองคุย 3 วัน, รายงาน/บล็อก, ไม่แชร์ข้อมูลติดต่อจนทั้งคู่ยืนยัน |
| โหมดไม่มีใครเห็นชั่วคราว | เปิดอัตโนมัติ 14 วันแรก จากนั้น *ถาม* ก่อนเปิดเผย ไม่เปิดเองอัตโนมัติ; ระดับการมองเห็น: เฉพาะฉัน → เพื่อนสนิท → ห้อง/คณะ → ทั้งโรงเรียน |
| Exit survey | เมื่อ streak ขาด ถามเหตุผลแบบไม่กดดัน (ไม่บังคับ) |
| **Phase 2:** Battle Pass ซีซั่นแรก | ซีซั่นละ 35 วัน, 12 tier (80 XP/tier ≈ เช็คอิน 5 วัน/สัปดาห์ถึง tier สุดท้าย), แถวฟรี + Premium, ของรางวัลเป็น cosmetic/เหรียญ/แพ็กการ์ดเท่านั้น ไม่มี XP boost |
| **Phase 2:** ราคาไทย + fake door test | Premium สุ่มแสดงราคา 59 หรือ 99 บาทต่อผู้ทดสอบ, ปุ่ม “ซื้อเอง” และ “ขอให้ผู้ปกครองซื้อให้” (Parent-pay) นับคลิกไว้ แล้วปลดล็อกให้ทดลองฟรี ไม่มีการเก็บเงินจริง |
| **Phase 2:** School League Leaderboard | อันดับรายสัปดาห์ (รีเซ็ตวันจันทร์) วัดจาก XP เฉลี่ยต่อสมาชิก โรงเรียนเล็กก็ชนะได้, ไม่มีอันดับรายบุคคล, XP ถูกนับเมื่อผู้ใช้เลือกเปิดระดับโรงเรียนเท่านั้น, ป้ายอันดับโรงเรียนโชว์ในมินิรูม |
| **Phase 3:** Inter-school Tournament | แพ้คัดออก 8 สถาบันพาร์ทเนอร์ในสัปดาห์ที่ 2–4 ของซีซั่น, คะแนน = % สมาชิกที่ขยับ ≥3 วันในสัปดาห์ (ทุกคนช่วยได้เท่ากัน), โรงเรียนที่ยังไม่เข้าร่วมมีปุ่ม “ชวนครูพละ” (B2B2C fake door นับไว้ใน `fakeDoor.teacherInvites`) |
| **Phase 3:** Local Brand Redemption | แลกเหรียญเป็นคูปองร้านใกล้โรงเรียน (จำลอง 5 ร้าน) สัปดาห์ละ 1 ใบ ใช้ได้ 7 วัน, มีโค้ด + QR ให้พนักงานกดยืนยัน, ไม่มีพาร์ทเนอร์ยาลดน้ำหนัก/อาหารเสริมลดน้ำหนัก |
| **Phase 2:** Collectible Cards | การ์ดความสำเร็จ 13 ใบจาก milestone ความสม่ำเสมอ + โฟโต้การ์ด 12 ใบ (ธรรมดา/หายาก/ลิมิเต็ด) จากแพ็กใน Battle Pass, ใบซ้ำแลกกับเพื่อนในแก๊ง/บัดดี้ได้ |

### เครื่องมือทดสอบ (แท็บ “ฉัน”)

- **ข้ามไปวันถัดไป** จำลองวันเพื่อทดสอบ streak / freeze / group streak / exit survey โดยไม่ต้องรอจริง
- **ส่งออกข้อมูลทดสอบ** ดาวน์โหลด JSON ของ session (เช็คอิน อารมณ์ คำตอบ exit survey, ราคา Premium ที่เห็น, จำนวนคลิก `fakeDoor`, คูปองที่แลก) ไว้วิเคราะห์ D2/D7 retention และความยินดีจ่าย
- **เริ่มใหม่ทั้งหมด** ล้างข้อมูลเพื่อให้ผู้ทดสอบคนถัดไปใช้

เพื่อน กลุ่ม และบัดดี้ในแอปเป็นผู้ใช้จำลอง (`js/data.js`) ที่เช็คอินแบบสุ่มคงที่ต่อวัน เพื่อให้ฟีเจอร์คอมมิวนิตี้ทดสอบได้โดยไม่ต้องมีเซิร์ฟเวอร์

## โครงสร้างไฟล์

```
index.html        หน้าเดียวของแอป
css/style.css     ธีม soft/pastel แบบเกาหลี
js/logic.js       กฎล้วน: วันที่, streak + freeze, XP/เลเวล, group streak, ซีซั่น/tier, League, ทัวร์นาเมนต์, คูปอง
js/data.js        ข้อมูลสถาบัน กิจกรรม ไอเท็ม รางวัล Battle Pass การ์ด ร้านพาร์ทเนอร์ และผู้ใช้จำลอง
js/engine.js      action ของผู้เล่น + validation (ใช้ทั้งเบราว์เซอร์และเซิร์ฟเวอร์)
js/local.js       backend ออฟไลน์ (เพื่อนจำลอง)
js/remote.js      backend ออนไลน์ (เรียก API)
js/app.js         UI
server/           เซิร์ฟเวอร์: HTTP + API, SQLite, บัญชีผู้ใช้
landing/          หน้าลงชื่อรอเปิดตัว + A/B test (index.html, landing.css, landing.js)
tests/            เทสต์ด้วย node:test (logic, engine, server integration)
admin/            หน้าผลการทดสอบสำหรับทีมงาน (ต้องใช้ ADMIN_TOKEN)
docs/             แผนธุรกิจ, landing page, backend, การ deploy
Dockerfile        image สำหรับ deploy (fly.toml = ตั้งค่า Fly.io)
```

## ขั้นต่อไป

ฟีเจอร์ตามแผนครบทั้ง MVP, Phase 2 และ Phase 3 แล้วในรูปแบบ prototype ดู [`docs/business-plan.md`](docs/business-plan.md) สำหรับสรุปแผนธุรกิจ, metric ที่ใช้วัดผล และสิ่งที่ต้องทำก่อนเป็นแอปจริง (backend, ระบบบัญชีผู้ใช้, การชำระเงิน, ระบบพาร์ทเนอร์)
